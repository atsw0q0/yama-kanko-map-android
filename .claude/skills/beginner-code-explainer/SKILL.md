# Android初学者向けコード解説・ナレッジ化スキル

このスキルは、Android開発初学者（ビギナー）に対して、実装されたコードや機能を直感的・論理的に理解できるよう解説ドキュメントを作成するための標準規則・フォーマットを定義します。

## 解説作成の核心ルール

1. **「なぜそのコードが必要なのか」を平易な日本語で先に説明する**:
   - 専門用語の羅列を避け、「仕組み」「背景」を最初にたとえ話や概念図、短い段落で解説する。

2. **構成フォーマットの厳格化**:
   すべての解説ドキュメントは以下のセクション構造に従って作成する：

   ```markdown
   # [タイトル] 初心者向け機能＆実装ガイド

   本文書は、Android開発初学者（ビギナー）に向けて、[対象アプリ/機能名] で実装された各機能の仕組みと「なぜそのコードが必要なのか」を分かりやすく解説したナレッジガイドです。

   ---

   ## 💡 実装した機能の一覧（サマリー表）

   | 機能名 | 概要 | 主な使用技術 / API |
   | :--- | :--- | :--- |
   | **1. 機能名1** | 機能の簡潔な説明 | `使用API`, `クラス名` |

   ---

   ## 🔰 各機能の仕組みと実装コード

   ### 1. [機能タイトル]

   #### 仕組み
   - なぜこの機能/クラスが必要なのか
   - スマホのOSや内部で何が起きているか

   #### コード解説
   ```kotlin
   // コード内コメントを豊富に記載し、初心者でも追いやすくする
   ```

   ---

   ## 🌟 初学者が覚えておくべきポイントまとめ

   1. **用語/概念1**: ポイント解説
   2. **用語/概念2**: ポイント解説
   ```

3. **コード内コメントの充実**:
   - サンプルコード内には `// 1. ～` や `// 【条件1】 ～` のように処理順序や条件の意図をわかりやすく記述する。

4. **保存先の決定**:
   - 全プロジェクト共通のナレッジは `docs/dev/` 配下に `.md` 形式で保存し、`docs/README.md` のインデックスに追加する。
