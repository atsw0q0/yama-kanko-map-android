# Android初学者向けコード解説・ナレッジ化スキル

このスキルは、Android開発初学者（ビギナー）に対して、実装されたコードや機能を直感的・論理的・根拠に基づいて理解できるよう解説ドキュメントを作成するための標準規則・フォーマットを定義します。

## 核心原則（絶対に守るべき規則）

1. **公式一次資料の検索・根拠URL記載の義務付け**:
   - 推奨手法や非推奨（Deprecated）API、セキュリティ基準、データベース選定基準等を記載する際は、**必ずWeb検索等でGoogle公式ドキュメント（Android Developers）、公式Release Notes、OWASP、NIST、ライブラリ公式リファレンスを最優先で検索・確認する**。
   - ナレッジドキュメント内には**必ず公式ドキュメントへの参照リンク（URL）および一次情報に基づく非推奨・推奨理由**を明記する。

2. **「なぜそのコードが必要なのか」を平易な日本語で先に説明する**:
   - 専門用語の羅列を避け、「仕組み」「背景」を最初にたとえ話や概念図、短い段落で解説する。

3. **構成フォーマットの厳格化**:
   すべての解説ドキュメントは以下のセクション構造に従って作成する：

   ```markdown
   # [タイトル] 初心者向け機能＆実装ガイド（公式文献・URL根拠付き）

   本文書は、Android開発初学者（ビギナー）に向けて、[対象アプリ/機能名] で実装された各機能の仕組みと「なぜそのコードが必要なのか」を分かりやすく解説した公式一次資料付きナレッジガイドです。

   ---

   ## 💡 実装した機能の一覧（サマリー表）

   | 機能名 | 概要 | 主な使用技術 / API | 公式ドキュメント / 根拠 |
   | :--- | :--- | :--- | :--- |
   | **1. 機能名1** | 機能の簡潔な説明 | `使用API`, `クラス名` | [公式リンク](https://...) |

   ---

   ## 🔰 各機能の仕組みと実装コード（公式根拠付き）

   ### 1. [機能タイトル]

   #### 仕組みと背景（公式根拠）
   - なぜこの機能/クラスが必要なのか
   - スマホのOSや内部で何が起きているか
   - **公式ドキュメント参照先**: [Android Developers: ...](https://...)

   #### コード解説
   ```kotlin
   // コード内コメントを豊富に記載し、初心者でも追いやすくする
   ```

   ---

   ## 🌟 初学者が覚えておくべきポイントまとめ

   1. **用語/概念1**: ポイント解説（参照: [公式リンク](https://...)）
   2. **用語/概念2**: ポイント解説
   ```

4. **コード内コメントの充実**:
   - サンプルコード内には `// 1. ～` や `// 【条件1】 ～` のように処理順序や条件の意図をわかりやすく記述する。

5. **保存先の決定**:
   - 全プロジェクト共通のナレッジは `docs/dev/` 配下に `.md` 形式で保存し、`docs/README.md` のインデックスに追加する。
